# Online Courses Catalog – Test Task  
**Pixel-perfect • Fully fluid adaptive • Vanilla JS + SCSS + BEM • Zero frameworks**

## Features

- Pixel-perfect match with the Figma design (1920 px → 320 px)  
- Fully fluid responsive layout — no media queries, no fixed breakpoints  
- Live search by course title (instant, no page reload)  
- Category filtering with dynamic counters  
- “Load more” pagination that respects filters and search  
- Strict BEM methodology 
- Pure HTML + vanilla JavaScript + SCSS   

## Quick start (development)

```bash
# 1. Clone / download the repo
git clone https://github.com/Yuliafire/courses-test.git
cd course-catalog

# 2. Install dependencies (Vite)
npm install

# 3. Run dev server 
npm run dev
# Open http://localhost:5173
